1. Что такое NEBULA Oracle

NEBULA Oracle — программа для анализа криптовалютного рынка. Она собирает публичные данные с бирж (Gate.io, Binance, Bybit, OKX, MEXC), рассчитывает технические индикаторы, метрики крупных игроков и формирует оценки на основе алгоритмов и искусственного интеллекта.

2. Не является финансовой рекомендацией

Вся информация в приложении носит исключительно информационный и образовательный характер. Это НЕ инвестиционный совет, НЕ рекомендация к покупке или продаже, НЕ руководство к действию. Любые торговые решения вы принимаете самостоятельно и под свою ответственность.

3. Риски

Торговля криптовалютами связана с высоким риском полной потери вложенных средств. Рынок волатилен, прогнозы не гарантированы, прошлые результаты не означают будущих. Не торгуйте на средства, потерю которых не можете себе позволить.

4. Точность данных и алгоритмов

Программа использует публичные API бирж и AI-модели. Мы не гарантируем:

Данные предоставляются «как есть», без каких-либо гарантий.

О программе

NEBULA

ORACLE · TRADING TERMINAL · v2.0

Что это

Персональный торговый терминал для криптовалютного рынка. Задуман как инструмент, который даёт обычному трейдеру то, что обычно доступно только профессионалам: глубокий анализ рынка, метрики крупных игроков и AI-наставника в одном окне.

Кто создал

Проект сделан одним человеком — трейдером-энтузиастом — в сотрудничестве с AI-помощником. Без команды, без инвестиций, без офиса.

Что умеет

  • Анализ монет с 5 бирж одновременно (Gate.io, Binance, Bybit, OKX, MEXC);
  • Whale-радар: Z-score объёмов, OBV, Open Interest, Long/Short Ratio, Taker Buy/Sell;
  • AI-наставник — объясняет простым языком, что происходит с монетой;
  • Сканер дна по топ-200 монетам;
  • Технический анализ: MACD, Bollinger, ADX, Stoch RSI, дивергенции, S/R, Volume Profile;
  • Торговый план, калькулятор сетки, отправка ордеров на MEXC;
  • Портфель с синхронизацией и курсом USDT/RUB;
  • AI-Агент — торговые команды на естественном языке;
  • TWAP — плавное исполнение крупных ордеров;
  • Шифрование API-ключей — AES-256-GCM + PBKDF2 через Web Crypto.

Технологии

TypeScript · Vite · Capacitor · Web Crypto · Groq API
