⚠️ Соглашение

Пожалуйста, прочитайте внимательно перед использованием NEBULA Oracle Terminal.

1. Что такое NEBULA Oracle

NEBULA Oracle — программа для анализа криптовалютного рынка. Она собирает публичные данные с бирж (Gate.io, Binance, Bybit, OKX, MEXC), рассчитывает технические индикаторы, метрики крупных игроков и формирует оценки на основе алгоритмов и искусственного интеллекта.

2. Не является финансовой рекомендацией

Вся информация в приложении носит исключительно информационный и образовательный характер.

3. Риски

Торговля криптовалютами связана с высоким риском полной потери вложенных средств.

О программе

NEBULA

ORACLE · TRADING TERMINAL · v2.0.37

Что такое NEBULA

Персональный торговый терминал для криптовалютного рынка. Задуман как инструмент, который даёт обычному трейдеру то, что обычно доступно только профессионалам: глубокий анализ рынка, метрики крупных игроков и AI-наставника в одном окне.

Кто создал

Проект сделан одним человеком — трейдером-энтузиастом — в сотрудничестве с AI-помощником. Без команды, без инвесторов, без офиса. Просто идея и желание сделать удобный инструмент для себя и других.

Что умеет

Платформы

  • 🌐 Web — работает в любом современном браузере;
  • 💻 Windows — нативное приложение через Tauri 2 (Rust + WebView2);
  • 📱 Android — APK через Capacitor 8 (без Google Play).

Безопасность

API-ключи MEXC и Groq-ключ хранятся только локально на вашем устройстве. Шифрование — AES-256-GCM + PBKDF2 (150 000 итераций). Мастер-пароль не сохраняется ни на сервере, ни в облаке и не покидает устройство. Даже автор программы не имеет к нему доступа.

Технологии

TypeScript · Vite 5 · Tauri 2 · Capacitor 8 · lightweight-charts 4.2 · Web Crypto · Groq API · Web Worker

Версия и сборка

NEBULA Oracle Terminal · v2.0.37
Сборка: Tauri (Windows) + Capacitor (Android) + Web
Идентификатор: com.nebula.oracle

⚠️ NEBULA — это инструмент анализа, а не финансовый советник. Все торговые решения вы принимаете самостоятельно и под свою ответственность. Рынок волатилен, прогнозы не гарантированы. Не торгуйте на средства, потерю которых не можете себе позволить.
