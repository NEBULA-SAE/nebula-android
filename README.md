## 📖 О проекте

**NEBULA Oracle** — это приложение, которое даёт обычному трейдеру то, что обычно доступно только профессионалам: глубокий анализ рынка, метрики крупных игроков и AI-наставника — всё в одном окне.

Проект собран **одним человеком** — трейдером-энтузиастом — в сотрудничестве с AI-помощником. Без команды, без инвестиций, без офиса.

## ✨ Что умеет

### 📊 Анализ рынка
- Свечи одновременно с **5 бирж**: Gate.io, Binance, Bybit, OKX, MEXC
- Технические индикаторы: **RSI, MACD, Bollinger, ADX, Stoch RSI, ATR**
- Дивергенции (bullish / bearish) с оценкой силы
- Уровни поддержки и сопротивления (кластеризация пивотов)
- Volume Profile (POC + Value Area)
- Режим рынка: bull / bear / altseason / neutral
- Календарь **Fear & Greed Index**, BTC-доминация, капитализация

### 🐋 Whale-радар
- Z-score объёмов (аномалия > 2.5σ)
- OBV slope — скрытое накопление / распределение
- Агрегированный стакан с 5 бирж с **anti-spoof фильтром**
- Open Interest, Long/Short Ratio, Taker Buy/Sell (Bybit + OKX)
- Комбинированный **Whale Score 0–100**

### 🔮 Oracle — самообучающийся движок
- Скоринг из 8 компонентов: tech + whale + orderbook + funding + onchain + market + learned weight
- Вердикты: `strong_buy` / `buy` / `hold` / `avoid`
- **Память**: сохраняет каждый анализ в localStorage
- **Обучение**: через 12+ часов проверяет исход (MFE / MAE) и формирует паттерны с win-rate
- Учитывает персональный **риск-профиль** (conservative / balanced / aggressive)

### 🤖 AI-наставник
- Разбор монеты **простым языком** для новичка
- 7 структурированных блоков: что происходит / на что похоже / почему так / за и против / сценарии с вероятностями / что делать / уверенность
- Работает через **Groq API** (модель `openai/gpt-oss-120b`)

### ⚡ AI-Агент
- Торговые команды **на естественном языке**: _«купи DASH на 10% депо»_
- AI парсит команду в JSON и исполняет через **MEXC API**
- Поддерживает `grid`, `market_buy`, `market_sell`, `cancel_all`

### 💸 TWAP
- Разбивает крупный ордер на N слайсов с джиттером ±10%
- Равномерное исполнение — меньше проскальзывания
- Живой прогресс-бар

### 🔍 Сканер дна
- Проходит топ-200 монет через Web Worker в 5 параллельных потоков
- Ищет техническое дно: RSI + отскок + падение

### 💼 Портфель
- Балансы с MEXC, курс USDT/RUB (OKX + ЦБ РФ, усреднение)
- PnL 24h, распределение активов

### 🛡️ Безопасность
- **Мастер-пароль** (PBKDF2, 150 000 итераций, AES-256-GCM)
- API-ключи шифруются, пароль живёт только в памяти сессии
- HMAC-SHA256 подпись запросов к бирже через Web Crypto

### 🌐 Прочее
- Полная двуязычность **RU / EN**
- Диагностика систем: 40+ проверок (библиотеки, DOM, прокси, биржи, Web Worker, Web Crypto)
- Радар сети **DASH**: мастерноды, хешрейт, сложность (GetBlock + Allnodes + Blockchair)
- Мобильный bottom-nav → сайдбар на десктопе
- Splash-screen, кастомные тултипы, тосты, модалки

## 🚀 Установка и запуск

### Требования

- **Node.js** ≥ 20
- **npm** ≥ 10
- (для Android) **Android Studio** + JDK 17

### Установка

```bash
git clone https://github.com/NEBULA-SAE/nebula-android.git
cd nebula-android
npm install

Режим разработки (браузер)
bash

npm run dev

Открой http://127.0.0.1:5173. Vite проксирует запросы к биржам через /proxy/* (см. vite.config.ts).
Проверка типов
bash

npm run check

Сборка
bash

npm run build

Результат — в папке dist/.
📱 Сборка Android APK
bash

# 1. Собрать веб-часть
npm run build

# 2. Синхронизировать с Android
npx cap sync android

# 3. Открыть в Android Studio
npx cap open android

Далее в Android Studio: Build → Build Bundle(s) / APK(s) → Build APK(s).

В APK CapacitorHttp патчит fetch на нативный HTTP — это обходит CORS и позволяет обращаться к биржам напрямую.
⚙️ Первый запуск

    Прими соглашение (модалка при первом входе).

    Установи мастер-пароль — им будут шифроваться API-ключи и Groq-ключ.

        Хранится только в памяти до закрытия приложения.

        Если забыть — ключи придётся вводить заново.

    Groq API-ключ (для AI-функций): получить бесплатно на console.groq.com/keys → вставить в настройках (⚙️ в топбаре).

    MEXC API-ключ (для торговли и портфеля): создать в MEXC API Management → вставить в шите «Ордера».

🔐 Безопасность

    Все секреты (API-ключи, Groq key) шифруются AES-256-GCM с ключом, производным от мастер-пароля через PBKDF2 (150 000 итераций, SHA-256).

    Пароль не сохраняется на диск — только в памяти сессии.

    Подпись запросов к бирже — HMAC-SHA256 через Web Crypto API.

    CapacitorHttp не логирует ключи и заголовки.

⚠️ Важно: приложение не отправляет ваши ключи на сторонние серверы. Вся криптография — локально.
