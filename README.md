## 📖 О проекте

**NEBULA Oracle** — это кроссплатформенное приложение, которое даёт обычному трейдеру то, что обычно доступно только профессионалам: глубокий анализ рынка с 5 бирж, метрики крупных игроков и AI-наставника — всё в одном окне.

Проект собран **одним человеком** — трейдером-энтузиастом — в сотрудничестве с AI-помощником. Без команды, без инвестиций, без офиса.

## ✨ Что умеет

### 📊 Анализ рынка и интерфейс
- Свечи одновременно с **5 бирж**: Gate.io, Binance, Bybit, OKX, MEXC.
- Технические индикаторы: **RSI, MACD, Bollinger, ADX, Stoch RSI, ATR**.
- Дивергенции, уровни поддержки/сопротивления, Volume Profile (POC + VA).
- Определение режима рынка: bull / bear / altseason / neutral.
- **Радиальное меню (Радар)** на мобильных устройствах с лазерным прицелом и тактильной отдачей.
- Кастомный Топбар для ПК (Tauri) с иконкой волка, статус-лампой и анимацией.
- Адаптивный дизайн: мобильный bottom-nav и ПК-сайдбар.

### 🐋 Whale-радар
- Z-score объёмов, OBV slope (скрытое накопление/распределение).
- Агрегированный стакан с 5 бирж с **anti-spoof фильтром**.
- Open Interest, Long/Short Ratio, Taker Buy/Sell (Bybit + OKX).
- Комбинированный **Whale Score 0–100**.

### 🔮 Oracle — самообучающийся движок
- Скоринг из 8 компонентов: технический анализ, киты, стакан, funding, on-chain, рыночный контекст, обученные веса.
- Вердикты: `strong_buy` / `buy` / `hold` / `avoid`.
- **Память**: сохраняет анализ в localStorage, через 12+ часов проверяет исход (MFE / MAE).
- Учитывает персональный **риск-профиль**.

### 🤖 AI-наставник и Агент
- Разбор монеты простым языком через **Groq API**.
- Парсинг торговых команд на естественном языке («купи DASH на 10% депо») в JSON.
- Исполнение ордеров на бирже.

### 💸 TWAP и Портфель
- **TWAP**: разбивает крупный ордер на слайсы с джиттером для уменьшения проскальзывания.
- **Портфель**: балансы с MEXC, курсы USDT/RUB (OKX + ЦБ РФ), PnL 24h.

### 🧪 Демо-режим
- Виртуальный баланс $10 000.
- Исполнение плана Оракула, учёт PnL и **мгновенный сброс** прогресса.
- Сохранение виртуальных ордеров при выходе/входе.

### 🌐 Прочее
- Полная двуязычность **RU / EN**.
- Диагностика систем (40+ проверок).
- Радар сети **DASH** (мастерноды, хешрейт, сложность).
- Кастомные темы, splash-screen, тултипы, модалки.

## 🛠️ Стек

| Слой | Технология |
|------|-----------|
| Язык | **TypeScript 5** (strict) |
| Сборка | **Vite 5** |
| Мобильная обёртка | **Capacitor 8** (Android) |
| ПК обёртка | **Tauri 2** (Rust + WebView2) |
| Графики | **Lightweight Charts 4.2** |
| Криптография | **Web Crypto API** (AES-GCM, PBKDF2, HMAC) |
| AI | **Groq API** (`openai/gpt-oss-120b`) |
| Хранение | **localStorage**, `sessionStorage` |
| Тяжёлые вычисления | **Web Worker** |
